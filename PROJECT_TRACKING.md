## ⚡ Quantum Command Cockpit (Hybrid A+B) Design Architecture

### Concept & Design Decisions
To elevate the portal to global state-of-the-art visual standards, the system adopted **Hybrid A+B**, merging:
- **Theme A (Deep-Space Quantum HUD)**: Mission-critical aerospace telemetry, micro-radar beacons, and numeric status readouts.
- **Theme B (Interactive AI Playground)**: Interactive terminal prompts, real-time typewriter synthesis, and 1-click execution actions.

### Core Architectural Features Built
1. **Interactive AI Command Terminal (`src/components/home/CommandTerminal.tsx`)**:
   - 5 built-in interactive preset prompts:
     - `Check Core System Health`
     - `Show WhatsApp CRM Architecture`
     - `How does ClassPulse track lectures?`
     - `Explain Zero-Data-Leakage Policy`
     - `Launch ScholarCard Print Engine`
   - Custom terminal input handling for free-form queries with live typewriter token generation.
   - 1-click contextual action buttons (e.g. launching live apps or opening architecture blueprints directly from terminal responses).
2. **Hardware-Accelerated Conic Neon Borders**:
   - Implemented CSS `@property --border-angle` conic gradient animations:
     ```css
     @property --border-angle {
       syntax: "<angle>";
       inherits: false;
       initial-value: 0deg;
     }
     ```
   - Renders 60fps GPU-accelerated neon border sweeps around terminal shells and flagship product cards.
3. **Flight-Deck Telemetry Ribbon (`src/components/home/HeroSection.tsx`)**:
   - Active IST/UTC clock ticker with continuous updates.
   - Live telemetry indicators: `11ms Ping`, `13 Nodes Online`, `Zero Leak Privacy`.
4. **Reversible Theme Mode Switcher (`src/context/ThemeContext.tsx`)**:
   - Context provider wrapping the application with client-side state preservation in `localStorage`.
   - Floating dock button in the lower-right viewport + navigation pill in `Navbar.tsx`.
   - Instant toggle between:
     - **Quantum Cockpit (Hybrid A+B)**: Full avionics telemetry, terminal prompt, and rotating neon shaders.
     - **Classic Cyber Studio**: The previous high-elegance cyber layout with traditional action bars.
