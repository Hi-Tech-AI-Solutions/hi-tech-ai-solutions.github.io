## ⚡ Quantum Command Cockpit (Hybrid A+B) Design System

The corporate portal implements the **Quantum Command Cockpit (Hybrid A+B)** theme, combining high-velocity developer ergonomics with mission-critical avionics HUD aesthetics:

1. **Avionics Flight-Deck Telemetry Ribbon**: Real-time IST/UTC clock, sub-second latency (`11ms Ping`), active fleet tracking (`13 Nodes Online`), and cryptographic isolation tags.
2. **Interactive AAI Command Terminal**: Embedded terminal in the hero section featuring preset capability queries, live typewriter synthesis, and 1-click execution triggers.
3. **Hardware-Accelerated Conic Neon Borders**: CSS `@property --border-angle` conic gradient animations revolving smoothly around flagship cards and avionics instruments.
4. **Avionics Identity & Radar**: Every product card displays a dedicated `SYS_ID` avionic badge, operational telemetry chip, and pulsing radar sweep status.
5. **Reversible Theme Mode Switcher**:
   - Floating dock button in the bottom-right corner + header switcher pill (`[ ⚡ Quantum Cockpit | 🛡️ Classic Studio ]`).
   - Switch back to the previous classic design at any time with persistent state saved in `localStorage`.

- **Framework**: [Next.js 15.5.25](https://nextjs.org/) (App Router, Static Site Generation `output: 'export'`)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS + Cyberpunk CSS Design System (`#030712`, `#00F0FF`, `#8B5CF6`, `#10B981`)
- **Animations**: CSS `@property --border-angle`, Framer Motion, Vector SVG Canvas
- **CI/CD Deployment**: Automated GitHub Actions workflow (`.github/workflows/deploy.yml`) publishing directly to GitHub Pages
- **SEO & GEO Standards**: Schema.org JSON-LD graph, `/llms.txt`, `sitemap.xml`, `robots.txt`, and geographic geo-coordinates for Surat, India
